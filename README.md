# CD-Tower-defence

School project: a tower defence game themed around České dráhy (Czech Railways), built in Python with pygame by two students working as a pair.

> Status: project setup. The game idea, rules and documentation will be filled in as we plan and build.

## Running the game (will be filled in)


## Project layout

| Path | What it holds |
|---|---|
| `src/` | Game source code |
| `assets/` | Images, sounds, fonts |
| `docs/` | Project documentation (what the game is and what it does) |
| `CORRECTIONS-<name>.md` | Each person's log of fixes made to AI-written code |
| `CLAUDE.md` | Working rules shared by both people's Claude |

## How we work

See `CLAUDE.md`. Short version: plan first, code on a branch, test and fix, then merge into `main` in the terminal.
